# 맥컬러 파트너 분석: GNN 검증과 그래프 전이

`mcc_gnn_report.html`을 브라우저에서 열면 전체 결과를 확인할 수 있습니다. 인터넷이나 별도 서버가 필요 없습니다. SVG·PNG 그림은 `figures`에 있습니다.

## 결론

- 팀 득실 기준 관측 외국인 동료 1위는 **Cheick Diallo**입니다. 리바운드·골밑 마무리형 빅맨이 맞을 수 있다는 탐색 가설입니다. 파트너 간 차이의 경기 부트스트랩 구간은 0을 포함하므로 우월성이 확정되지 않았습니다.
- 맥컬러 개인 득점·TS 기준 관측 1위는 **Lasannah Kromah**입니다. 어시스트 생산량이 높은 플레이메이커형입니다. 팀 득실과 개인 공격 성과의 목적을 분리해야 합니다.
- 새 후보의 팀 성과 유형 전이 점수는 **Jordy Tshimanga**, **Brandon Gilbeck**, **Jason Washburn**, **Marko Todorovic** 순입니다. 실제 궁합을 예측·검증한 순위가 아니라 추가 스카우팅 대상입니다. 기존 동료 포함 35명, 제외하면 32명입니다.
- 관계형 GNN을 실제 학습했으나 경기 그룹 교차검증과 시간순 검증 모두 단순 평균·Ridge보다 나빴습니다. 따라서 GNN 순위를 최종 추천 근거로 채택하지 않았습니다. 그래프 전이도 예측 검증에 성공한 대체 모델이라는 뜻은 아닙니다. 불확실성을 드러내는 기술·탐색 분석입니다.
- 삼성 썬더스는 **KBL** 구단입니다. KBL의 외국인 **2명 보유·1명 출전** 규정상 이 TPBL 동시 출전 분석을 삼성의 두 외국인 동시 출전 궁합으로 적용할 수 없습니다. 삼성 교대 외국인 추천에는 국내 라인업·맥컬러 비출전 데이터가 필요합니다.

## GNN 구현

스틴트마다 10노드 그래프를 구성하고 동료 4명, 상대 5명의 특성을 각각 평균 집계합니다.

`H = tanh(X Wself + Ateam X Wteam + Aopp X Wopp + b)`

맥컬러 임베딩, 다른 동료 4명의 평균 임베딩, 상대 5명의 평균 임베딩과 구간 시작 맥락을 연결해 팀 득실/36분 및 맥컬러 득점/36분을 예측합니다.

- 특성 19개: 축소 36분당 points/FGA/three_PA/FTA/OREB/DREB/AST/STL/BLK/TOV 10개, 축소 3P%·TS, 신장, 포지션 멀티핫 5개, 외국인 여부.
- 축소: 생산량은 200분 사전값, 3P%는 50회 시도, TS는 분모 100. 모두 허용된 경기별 로그에서 리그 사전 평균을 계산합니다.
- 신장 결측은 선수 메타데이터 중앙값, 허용 기록이 없는 선수는 리그 사전 평균. 표준화 모집단은 메타데이터의 137명입니다.
- 맥락 4개: 홈 여부, 시작 득실/20, 정규시간 잔여 초/2880, 연장 여부.
- 은닉 8, 메시지 전달 1층, 학습 파라미터 **522개**. NumPy 역전파 및 Adam 구현.
- 지속시간 가중 MSE, 출력 스케일 `[40, 25]`, L2 0.02, lr 0.008, 220 epochs. 테스트 결과 기반 튜닝 없음.
- 매 검증 3개 seed 평균. 하이퍼파라미터 탐색을 한 결과가 아니며 GNN 전체의 성능 한계를 증명하지 않습니다.
- no-edge 모델은 같은 구조에서 동료·상대 메시지를 0으로 만든 ablation입니다. Ridge는 같은 역할별 평균 특성과 맥락에 정규화 가중 손실 λ=1을 적용합니다.

### 정보 누수와 검증

시즌 합계 `z_*`, 전체 시즌 엣지 가중치, `stint_nodes`의 구간 결과 스탯을 모델 입력으로 사용하지 않았습니다. 노드 인덱스는 선수 선택용이며 학습할 선수 ID 임베딩은 없습니다.

1. 5개 경기 그룹 교차검증: 동일 경기의 모든 구간을 한 fold로 묶고, 해당 테스트 경기 박스스코어는 특성·사전 평균 계산에서 제외합니다. 다른 날짜의 미래 경기는 포함될 수 있어 시즌 내 **회고 평가**입니다.
2. 시간순 검증: 마지막 8경기를 테스트로, 이전 16경기를 학습으로 사용합니다. 리그 선수 특성은 테스트 시작 날짜 이전의 기록만 사용합니다. 테스트 데이터로 표준화하거나 재학습하지 않습니다.
3. 테스트 라인업·시작 점수 차가 주어졌다는 조건에서의 성과 예측입니다. 경기 전 전체 결과 예측이나 인과 추정이 아닙니다.
4. 지속시간은 입력이 아니며 실제 길이를 이용해 타깃·손실 가중치만 정의합니다. 결과 포제션을 모델 입력으로 쓰지 않습니다.
5. 파트너 선호·성공 라벨은 없으므로 “동료 엣지 존재 = 좋은 궁합”, “미공출전 = 나쁜 궁합”으로 학습하지 않았습니다.

| 검증 | 모델 | 팀 득실 RMSE/36분 | 개인 득점 RMSE/36분 |
|---|---|---:|---:|
| 경기별 5분할 | GNN | 79.46 | 31.38 |
| 경기별 5분할 | 단순 평균 | 70.19 | 29.46 |
| 경기별 5분할 | Ridge | 70.18 | 29.42 |
| 경기별 5분할 | 엣지 제거 NN | 73.90 | 29.91 |
| 마지막 8경기 | GNN | 80.59 | 32.91 |
| 마지막 8경기 | 단순 평균 | 65.00 | 30.24 |
| 마지막 8경기 | Ridge | 65.01 | 30.12 |
| 마지막 8경기 | 엣지 제거 NN | 72.46 | 30.52 |

짧은 구간의 36분 환산값은 변동성이 크므로 오차 절대값도 큽니다. RMSE를 선수 36분 실제 경기의 득점 오차로 해석하면 안 됩니다. 경기 단위 재표집으로 고정된 검증 예측의 오차 차이를 비교했습니다. 해당 구간은 CV 모델을 다시 학습하는 불확실성까지 포괄하지 않습니다.

## 대체 그래프 방법

1. **관측 그래프:** 맥컬러–동료의 실제 공출전 시간을 엣지로 둡니다. 엣지 성과는 해당 구간의 팀 득실/36분입니다. 팀 득실은 상대·국내 동료·경기 상황이 모두 섞인 결과이며 동료의 독립적 효과가 아닙니다.
2. **축소:** `r_j = (36 × 득실_j + 120 × 전체_평균_득실36) / (공출전분_j + 120)`.
3. **유형 전이:** 30분 이상 함께 뛴 외국인 동료 3명이 기준점입니다. 시즌 200분 이상 외국인 후보와 각 기준점의 8개 특성 거리를 계산합니다. 특성은 3PA/OREB/DREB/AST/BLK/TOV per36 및 3P%·TS. 전체 허용 시즌 기록을 써서 표준화합니다. GNN 검증과 별개의 시즌 회고 기술 분석입니다.
4. **가중치:** `d(c,j)² = mean((z_c - z_j)²)`, `w(c,j) ∝ exp(-d²/(2×bandwidth²))`, 기본 bandwidth=1. 후보 점수는 `sum(w × r_j)`입니다. 개인 득점 전이도 같은 방식으로 계산합니다.
5. **불확실성:** 24경기를 2,000회 복원추출하며 관측값·사전 평균을 다시 계산합니다. 후보 특성 및 유사도 가중치는 고정입니다. 따라서 표시 구간은 후보의 진짜 경기력 예측 구간이 아닙니다.
6. **민감도:** 사전 표본 60/120/240분 × bandwidth 0.5/1/2. 기존 동료 포함 35명 중의 순위를 저장합니다. 또한 짧은 구간·가비지를 포함한 관측 성과와 비교합니다.

- `gnn_model_*.npz`, `final_feature_state.npz`: 가상 교체에 사용한 모델/특성 상태.
- `analysis_stints.csv`: 주분석 표본.
- `qa_results.json`, `output/playwright/`: 화면·인터랙션 검사 기록과 스크린샷.

## 학회 발표용 문장

> 맥컬러의 TPBL 정규시즌 24경기에서 라인업 관계형 GNN을 학습했으나, 경기 단위 및 시간순 검증에서 단순 기준보다 낮은 성능을 보였다. 이에 관측 공출전 그래프와 선수 특성 전이로 분석 범위를 제한했다. 팀 득실에서는 디알로 조합, 개인 득점에서는 크로마 조합이 높은 관측값을 보였지만 파트너 간 차이는 불확실했다. 따라서 빅맨형과 플레이메이커형이라는 역할 가설 및 후속 스카우팅 후보를 제시하며, KBL 교대 외국인 영입 효과로 일반화하지 않는다.

참고: [R-GCN 원 논문](https://arxiv.org/abs/1703.06103), [KBL 경기 운영 규정](https://pegasus.kbl.or.kr/rule/operation).
